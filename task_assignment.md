# 🌐 Service Sphere

**Service Sphere** is a full-stack **Service Booking Platform** that connects **seekers** (users who need services) with **helpers** (service providers).  
Seekers can easily search, book, and review services, while helpers can manage their schedules, earnings, and requests.  
An integrated **Admin Dashboard** ensures efficient monitoring, user management, and platform analytics.

---

## ⚙️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript, EJS (Embedded JavaScript Templates)  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB  
- **Architecture:** MVC (Model–View–Controller) pattern with modular routing for admin, helper, and seeker functionalities

## 🧩 Summary of Services

**Service Sphere** provides a unified platform for managing service-based interactions efficiently:  
- **Seekers** can discover, compare, and book services offered by nearby helpers.  
- **Helpers** can accept requests, manage schedules, track earnings, and view feedback.  
- **Admins** can oversee user data, service analytics, and earnings reports through a centralized dashboard.  
- The system ensures **real-time updates**, **secure authentication**, and a **user-friendly interface**, making it easy for both seekers and helpers to collaborate effectively.
